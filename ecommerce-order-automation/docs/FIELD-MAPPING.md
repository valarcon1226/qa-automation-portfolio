# Field Mapping Specification: Multi-Source to Unified Order Model

This document specifies the exact mapping from inbound webhook payloads of three e-commerce platforms (**WooCommerce**, **Shopify**, and **Stripe**) to the normalized domain model (`Order`) in the Café de Origen automation system.

All mappings defined below are implemented in [app/normalizers.py](../app/normalizers.py) and typed via Pydantic in [app/models.py](../app/models.py).
